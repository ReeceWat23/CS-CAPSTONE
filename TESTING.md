## Ensure '''npm''' is installed and install the following:
```bash
npm install --save-dev jest
npm install --save-dev babel-jest @babel/core @babel/preset-env
```
## If the error is missing the yocto-queue module:
```bash
npm install yocto-queue
```

## To run tests:
```bash
npm test
```

## Configurations can be found in package.json
